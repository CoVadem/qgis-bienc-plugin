about=Processing algorithms (Processing Toolbox > CoVadem ENC) to load DEPARE depth areas from a folder of S-57 .000 files with a depth (DRVAL1) color gradient. S-57 files can first be converted to GeoParquet (one merged file or one file per source; in memory, next to the sources, in a temp folder or a custom folder), which renders much faster than reading many S-57 files directly. Converted files are cached and reused. Requires QGIS 4.0+ and the GDAL S-57 driver. GeoParquet conversion additionally requires the GDAL Parquet driver. No separate Python packages are required; the plugin uses the QGIS and GDAL Python APIs.
